# Arquitectura

Esta sección describe la arquitectura de SISGAL desde diferentes perspectivas, incluyendo la estructura general del sistema, los atributos de calidad considerados durante el diseño, las tácticas arquitectónicas implementadas y las decisiones que dieron origen a la solución.

El objetivo es proporcionar una visión clara de cómo está construido el sistema y las razones técnicas que sustentan su diseño.

## Contenido

- Visión general
- Arquitectura Backend
- Arquitectura Frontend
- Atributos de calidad
- Tácticas arquitectónicas
- Escenarios de calidad
