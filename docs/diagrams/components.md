# Componentes de SISGAL (C4, Nivel 3)

El nivel 3 detalla la organización interna de los dos clientes principales de SISGAL:

- [Componentes del Backend Core](components-backend.md): módulos de negocio y sus dependencias con el dispositivo biométrico y las bases de datos.
- [Componentes del Frontend](components-frontend.md): navegación, funcionalidades, presentación y comunicación con el backend.

El módulo de auditoría se representa como una propuesta transversal. La integración y persistencia de auditoría todavía están por definir.

Los diagramas de base de datos y de secuencia siguen [pendientes de validación](index.md#vistas-pendientes).
