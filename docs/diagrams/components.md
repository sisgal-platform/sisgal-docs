# Componentes de SISGAL (C4, Nivel 3)

El nivel 3 detalla los dos componentes de aplicación actuales:

- [Componentes del Backend Core](components-backend.md): módulos de negocio y persistencia.
- [Componentes del Frontend](components-frontend.md): navegación, funcionalidades, presentación y comunicación con el backend.

El módulo y el almacenamiento de auditoría se muestran como diseño pendiente, no como integración activa. La integración biométrica no está implementada.

La vista de datos de auditoría y el diagrama de secuencia se describen desde [Diagramas](index.md).
