## Objetivo del Sprint

El objetivo del Sprint 01 fue establecer las funcionalidades iniciales de interacción con el sistema SISGAL, incluyendo el acceso seguro, la navegación entre módulos, el panel administrativo y la adaptación de la interfaz a dispositivos móviles.

Estas funcionalidades corresponden a elementos transversales que sirven como base para la construcción y utilización de los demás módulos del sistema.

## Resultado del Sprint

Las cuatro historias de usuario seleccionadas para el Sprint fueron desarrolladas satisfactoriamente.

El incremento obtenido permitió disponer de una primera versión funcional de la interfaz del sistema, incorporando mecanismos de acceso, navegación entre módulos, visualización del panel administrativo y adaptación de la interfaz para diferentes tamaños de pantalla.

## Aspectos relevantes

- Se establecieron las funcionalidades iniciales de interacción con SISGAL.
- Se precisaron los criterios de aceptación de las historias durante el refinamiento.
- Se validó la navegación entre los diferentes módulos.
- Se trabajó en la adaptación responsive de la interfaz.
- No se presentaron bloqueos que afectaran el desarrollo del Sprint.
