## Objetivo

Analizar el desarrollo del Sprint 01, identificar aspectos positivos, dificultades y oportunidades de mejora para los siguientes Sprints.

## ¿Qué salió bien?

- Las cuatro historias comprometidas fueron completadas.
- El equipo mantuvo comunicación durante el desarrollo.
- No se presentaron bloqueos que afectaran el cumplimiento del Sprint.
- Se logró establecer una base funcional para continuar con los siguientes módulos.

## ¿Qué podría mejorar?

- Definir con mayor anticipación los criterios de aceptación.

- Mejorar la planificación del trabajo para facilitar el seguimiento del avance.
- Mantener registros consistentes de las ceremonias y acuerdos del equipo.
