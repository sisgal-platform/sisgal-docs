## Objetivo del Sprint

Implementar las funcionalidades iniciales de acceso, navegación, administración y visualización responsive de SISGAL, estableciendo una base funcional para el desarrollo de los siguientes módulos.

## Alcance del Sprint

Durante el Sprint se definió trabajar exclusivamente sobre las cuatro historias de usuario seleccionadas. El alcance se estableció a nivel de historia de usuario, dejando el detalle de tareas técnicas para la gestión interna del equipo.

### HU32 — Acceso seguro al sistema

Se definió implementar el acceso de los usuarios al sistema mediante un mecanismo de autenticación que permita controlar el ingreso a las funcionalidades de SISGAL.

### HU34 — Navegar entre módulos del sistema

Se definió implementar la navegación principal del sistema, permitiendo acceder de manera organizada a los diferentes módulos disponibles.

### HU33 — Panel administrativo centralizado

Se definió implementar un panel administrativo que concentre las principales funcionalidades y permita al usuario identificar y acceder a los módulos disponibles.

### HU36 — Visualizar sistema en dispositivos móviles

Se definió adaptar la interfaz de SISGAL para permitir su correcta visualización y utilización desde dispositivos con diferentes tamaños de pantalla.

## Dependencias

- Definición inicial de la estructura de navegación.
- Definición de los módulos principales del sistema.
- Disponibilidad de los componentes base de la interfaz.
- Definición de los criterios de aceptación de las historias.

## Acuerdos

- Mantener una estructura de navegación consistente entre los módulos.
- Priorizar una experiencia de usuario clara para las funcionalidades iniciales.
- Considerar desde el inicio la visualización en dispositivos móviles.
- Refinar los criterios de aceptación para hacerlos más específicos y verificables.

## Compromiso del Sprint

El equipo se comprometió a completar las cuatro historias de usuario seleccionadas y disponer de un incremento funcional que permitiera validar las funcionalidades iniciales del sistema.
