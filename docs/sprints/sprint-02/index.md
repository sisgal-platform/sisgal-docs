## Objetivo del Sprint

El objetivo del Sprint 02 es avanzar en la construcción de las funcionalidades principales de gestión de empleados y parametrización del sistema SISGAL.

El Sprint contempla funcionalidades para registrar y consultar empleados, visualizar el detalle de su información, establecer el modelo de base de datos requerido para estas funcionalidades y administrar los catálogos de sucursales y cargos.
