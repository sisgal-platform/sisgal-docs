## Resultado del Sprint

Durante la revisión se presentó el avance correspondiente a las seis historias de usuario comprometidas para el Sprint.

El equipo logró avanzar en las funcionalidades relacionadas con la gestión de empleados y la parametrización del sistema, siguiendo la secuencia de trabajo definida durante el Planning.

En el caso de las historias relacionadas con empleados, el desarrollo siguió la siguiente secuencia:

**HT → HU21 → HU39 → HU40**

Esta secuencia permitió establecer primero la estructura de datos necesaria y posteriormente desarrollar el registro, consulta y detalle de los empleados.

## Incremento presentado

Durante la Review se presentaron las siguientes funcionalidades:

- Modelo de base de datos requerido para la gestión de empleados.
- Registro de empleados.
- Consulta de información de empleados.
- Visualización del detalle de un empleado.
- Parametrización de sucursales.
- Parametrización de cargos.

## Retroalimentación

Durante la revisión se identificó la importancia de mantener consistencia entre las parametrizaciones y las funcionalidades de empleados, especialmente considerando que las sucursales y cargos hacen parte de la información utilizada en el proceso de gestión de empleados.

También se destacó la necesidad de continuar manteniendo criterios de aceptación específicos para facilitar la validación de las historias.

## Acuerdos

- Mantener la parametrización de sucursales y cargos como catálogos reutilizables por otros módulos.
- Continuar validando la integración entre las funcionalidades de empleados y las parametrizaciones.
- Mantener criterios de aceptación claros y verificables para las siguientes historias.
- Continuar con el desarrollo de las funcionalidades priorizadas para el siguiente Sprint.
