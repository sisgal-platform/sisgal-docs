# Glosario

Este glosario define los principales términos utilizados en la documentación funcional y técnica de SISGAL.

| Término | Definición |
| --- | --- |
| **Asistencia** | Información relacionada con las marcaciones y jornadas de trabajo de un empleado. |
| **Cargo** | Función o posición desempeñada por un empleado dentro de la organización. |
| **Empleado** | Persona vinculada a JS Burguer Parrilla cuya información laboral es gestionada mediante SISGAL. |
| **Incapacidad** | Novedad asociada a la ausencia temporal de un empleado y que puede afectar el proceso de liquidación de nómina. |
| **Jornada** | Periodo durante el cual un empleado realiza sus actividades laborales. |
| **Liquidación** | Proceso mediante el cual se calculan los valores correspondientes a un empleado para un periodo determinado. |
| **Marcación** | Registro de una entrada o salida realizada por un empleado mediante el mecanismo de control de asistencia. |
| **Nómina** | Proceso de cálculo de los valores que corresponden a los empleados durante un periodo de pago. |
| **Novedad** | Situación o concepto que puede modificar los valores utilizados en la liquidación de nómina. |
| **Préstamo** | Obligación económica registrada para un empleado que puede generar descuentos en la liquidación de nómina. |
| **Recargo** | Valor adicional generado por la realización de trabajo bajo determinadas condiciones, como trabajo nocturno, dominical o festivo. |
| **Salario base** | Valor de referencia establecido para el empleado y utilizado en determinados cálculos de nómina. |
| **Sucursal** | Establecimiento o ubicación perteneciente a la organización donde pueden encontrarse asignados los empleados. |
| **Usuario administrador** | Usuario encargado de realizar las operaciones administrativas disponibles en SISGAL. |
| **Novedad de nómina** | Evento o situación que modifica los valores considerados durante una liquidación. |
