# Seguridad

Describe los controles de seguridad implementados y los procedimientos para administrarlos.

## Información por completar

- Autenticación, autorización y roles.
- Manejo de datos personales y biométricos.
- Protección de secretos y credenciales.
- Transporte y almacenamiento de información.
- Registro de eventos y gestión de incidentes.
- Proceso para reportar vulnerabilidades.

Evita publicar credenciales, datos personales o detalles que faciliten el acceso indebido a sistemas.
