# Configuración

Describe las variables de entorno y los parámetros necesarios para ejecutar cada componente de SISGAL.

## Información por completar

- Archivos de ejemplo de configuración y su ubicación.
- Variables requeridas, propósito y si son secretas.
- Configuración de base de datos y servicios externos.
- Diferencias entre desarrollo, pruebas y producción.
- Validaciones que realiza la aplicación al iniciar.

Usa nombres de variables y valores de ejemplo no sensibles. Mantén los secretos fuera del repositorio.
