# Instalación y entorno de desarrollo

Documenta aquí los requisitos previos, la preparación del entorno y los pasos para ejecutar SISGAL localmente.

## Información por completar

- Versiones soportadas de Node.js, gestores de paquetes, Docker y PostgreSQL.
- Repositorios o módulos que deben clonarse.
- Instalación de dependencias del frontend y backend.
- Creación y migración de la base de datos.
- Comandos de inicio y verificación.
- Solución de errores frecuentes.

> Añade comandos solo después de verificarlos en el proyecto. No incluyas secretos ni valores reales de credenciales.
